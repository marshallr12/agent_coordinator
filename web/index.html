    Shared capacity

    Resources

    Resources represent limited capacity shared by agents across every project: for example, an exclusive test database, a licensed device, or a validation workstation.

    How resources coordinate work

    Define a resource before jobs need to compete for it. An agent reserves all required units before it starts its work and releases them only after the related job has terminal evidence, so another agent can safely use the available capacity.

    A reservation coordinates access only. It does not start or stop a job, and it is not proof that a job has run or finished.

    Define a resource

    Choose a stable, reusable key that identifies the shared capacity across projects.

    Use 1 when work must be exclusive; use a larger number only for interchangeable concurrent units.

    Describe what it is, who uses it, and any access constraint that matters.

    Capacity is fixed when created.
